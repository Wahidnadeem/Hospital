# صحت هرات — سیستم دیجیتال صحی هرات (HDHS)

سیستم مدیریت صحی برای شفاخانه‌ها، داکتران و خدمات صحت عامه ولایت هرات. رابط کاربری کاملاً راست‌به‌چپ و به زبان دری است، تاریخ‌ها به هجری شمسی با ماه‌های افغانی (حمل، ثور، … میزان) نمایش داده می‌شوند و روی موبایل، تبلت و کمپیوتر کار می‌کند.

## اجرا

- **بدون نصب:** فایل `index.html` را در مرورگر باز کنید. داده نمونه از `data/seed.js` بارگذاری می‌شود و تغییرات در حافظه همان مرورگر (localStorage) ذخیره می‌شوند.
- **GitHub Pages:** در تنظیمات ریپازیتوری ← Pages ← شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
- **ساخت دوباره از سورس:**
  ```bash
  node src/seed.cjs   # ساخت دوباره داده نمونه (data/seed.js)
  node build.cjs      # ساخت index.html و dist/artifact.html
  ```

## ماژول‌ها

| ماژول | امکانات |
|---|---|
| داشبورد | نوبت‌های ۱۴ روز، صف امروز، اشغال تخت، هشدارهای کلینیکی، بانک خون، روند بیماری‌ها |
| بیماران | ثبت با تذکره و MRN یکتا، پرونده کامل، حساسیت‌ها، علائم حیاتی و نمودار، نسخه‌ها، آزمایش‌ها، واکسین، پرداخت |
| نوبت‌دهی | ساعت‌های آزاد زنده بر اساس تقسیم اوقات داکتر، جلوگیری از نوبت تکراری، چرخه وضعیت (تأیید ← پذیرش ← ویزیت ← تکمیل) |
| ویزیت | علائم حیاتی با BMI و NEWS2، تشخیص ICD-10، نسخه الکترونیک با هشدار حساسیت و تداخل دارویی، درخواست آزمایش |
| دواخانه | صف نسخه‌ها، تحویل به روش «اول‌منقضی، اول‌خارج» (FEFO)، موجودی، هشدار کمبود و انقضا، دارونامه |
| لابراتوار | محدوده نورمال بر اساس سن و جنس، علامت‌گذاری خودکار، هشدار نتیجه بحرانی |
| مادر و طفل | ANC و تاریخ تخمینی ولادت، پایش رشد و MUAC (SAM/MAM)، برنامه واکسیناسیون EPI |
| نظارت بیماری‌ها | گزارش هفتگی IDSR، تشخیص خودکار شیوع، هشدار اپیدمی، توزیع ولسوالی‌ها |
| عاجل | تریاژ سرخ/زرد/سبز، اعزام نزدیک‌ترین امبولانس، بانک خون |
| سیستم | گزارش تغییرات (Audit)، ساختار جدول‌ها و رابطه‌ها، دسترسی بر اساس نقش |

## ساختار داده

- ۳۶ جدول رابطه‌ای با کلید خارجی، قید یکتا و قاعده حذف (محدود، آبشاری، خالی‌سازی) — تعریف در `src/schema.js`
- موتور داده در حافظه با شاخص روی همه کلیدهای خارجی؛ نوشتن‌ها تراکنشی هستند و در صورت خطا کامل برگشت داده می‌شوند (`src/store.js`)
- اسکیمای PostgreSQL برای نسخه تولیدی با همان رابطه‌ها: `database/schema.sql`

## ساختار پوشه‌ها

```
index.html            اپلیکیشن ساخته‌شده (مستقل)
data/seed.js          داده نمونه
src/                  سورس: schema, store, app1–4, styles, seed
database/schema.sql   اسکیمای PostgreSQL
dist/artifact.html    نسخه مخصوص Claude artifact (پایگاه داده مشترک)
build.cjs             اسکریپت ساخت
```

## یادداشت درباره داده‌ها

شفاخانه‌ها و ۳۲ داکتر از سند HDHS (وب‌سایت‌های رسمی شفاخانه‌ها) گرفته شده‌اند؛ معلوماتی که منتشر نشده (مثل نمبر جواز و فیس) خالی گذاشته شده است. **بیماران و سوابق کلینیکی داده نمونه هستند** و فقط برای آزمایش سیستم استفاده می‌شوند.

**HDHS — Herat Digital Health System.** RTL Dari web app (vanilla JS, no framework) with an indexed in-memory relational engine, transactional writes and pluggable persistence (browser storage standalone, shared database when hosted as a Claude artifact). Production PostgreSQL schema in `database/schema.sql`. Open `index.html` to run.
